# Set Up Project Folder Structure

Creates the standard folder structure used by the data cleaning
pipeline. Safe to run on an existing project — folders that already
exist are skipped with an informational message rather than overwritten
or errored.

## Usage

``` r
setup_project_folders(base_path = ".", extra_folders = NULL, verbose = TRUE)
```

## Arguments

- base_path:

  Root directory of the project. Default `"."` (current working
  directory). Use
  [`here::here()`](https://here.r-lib.org/reference/here.html) for
  reproducible paths inside an R project.

- extra_folders:

  Optional character vector of additional folder paths to create
  relative to `base_path` (e.g.
  `c("output/archive", "output/checking")`). Default `NULL`.

- verbose:

  Logical. If `TRUE` (the default), a message is printed for each folder
  showing whether it was created or already existed.

## Value

Invisibly returns a named logical vector: `TRUE` for each folder that
was newly created, `FALSE` for folders that already existed.

## Details

The following folders are created (relative to `base_path`):

- `data/`:

  Raw data exports from ONA or other XLSForm platforms.

- `resources/`:

  Supporting files: XLSForm tool, kobo/ONA choices, label files, logical
  check lists, etc.

- `output/`:

  All outputs generated by the pipeline.

- `output/follow_ups/`:

  The review workbooks -
  [`create_review_workbook()`](create_review_workbook.md) writes here,
  and the reviewer returns the filled file as `_follow-ups_edited.xlsx`
  (or `.xlsm`). One workbook now carries both the cleaning log and the
  other responses, so this is the only folder the second stage reads.

- `output/other_responses/`:

  Legacy. Only used by the standalone
  [`save_other_responses()`](save_other_responses.md) route, which
  writes a separate other-responses file. Still created so existing
  projects are unaffected.

- `output/final/`:

  Final output workbooks produced by
  [`export_final_output()`](export_final_output.md).
